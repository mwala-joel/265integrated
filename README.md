# 265Integrated

A minimal showcase portfolio for 265Integrated, an independent creative company in Malawi.

## Pages

- Home — company introduction, selected work, capabilities, and contact
- About — studio approach, services, and company perspective

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production checks

```bash
npm run lint
npm run build
```

Built with Next.js, TypeScript, and Tailwind CSS.
